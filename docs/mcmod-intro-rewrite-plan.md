## 一、结论：MUT 走「定位句 + 清单」路线

14 篇里出现频率最高的开篇是定位句，格式稳定为：

> 「X（原名）是一个以 __ 为核心、以 __ 为主题的 __ 向模组：」+ 分号清单 5–7 条

MUT 的定位句建议：

> MUT（MoreUpgradeTemplate：重生）是一个以锻造模板为核心、以装备词缀与符锻维度为主题的装备扩展向模组。

三条主线卖点（清单用）：

- 材质升级链：木 → 石 → 铁 → 铜 → 钢 → 钻石 → 蓝钻 → 绿宝石 → 紫水晶 → 黑曜石 → 下界合金 → 星辉 / 凋零 / 龙鳞
- 词缀与超级锻造台：8 档词缀等级、材料加成、软保底、数据包驱动与 /reload 热重载
- 符锻维度：12 个群系、6 种结构、32 个模板池，含符锻试炼与首领试炼

## 四、写法红线（来自样本的反面经验）

- 不写命名空间、代码架构、类名——14 篇样本中零出现
- 不写「超多」「大量」，一律换成数字或表格
- 不写裸的「开发中」「内容较少」，写成「已实装（版本号）/ 计划中」
- 一个模块一段话 + 一张图，段落控制在 150 字内
- 兼容性与风险提示用「注意」段前置，不要埋到最后
- 致谢、授权、维护者信息只放末尾一行
